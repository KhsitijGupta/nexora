# 3D Watch Models Directory

Place your custom 3D model here named:
`watch.glb`

When `watch.glb` is placed in this folder (`/public/models/watch.glb`), the CHRONOVA landing page will automatically detect and load it.
If `watch.glb` is absent, the application gracefully renders a high-precision procedural luxury mechanical watch model with custom metallic shaders, rotating gears, and sapphire transmission crystal.
